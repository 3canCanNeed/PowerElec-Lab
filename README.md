# PowerElec-Lab · 电电实验室

> 面向中文电力电子教学的**交互式仿真集合**——每个实验就是一个网页：零依赖、离线可用、拖滑块即时重算。
> 定位：配合《电力电子技术》（王兆安·第5版）等主流教材的"看得见"的实验台。

## 为什么做这个

- 电力电子课的难点全是**波形**：触发角、占空比、调制比对波形的影响，静态板书和 PDF 截图讲不动。
- 国外有 Falstad/EveryCircuit，但没有按国内教材口径（α 从自然换相点起算、双极性 SPWM、双闭环工程整定）组织的内容。
- 单文件 HTML 的形态在学生群体里传播力极强（可直接微信发送、离线打开）。

## 当前内容（v0.1 原型）

| 模块 | 可调参数 | 演示知识点 |
|---|---|---|
| 单相全控桥整流 | α、U₂、R/大电感负载 | 缺角波形、电流断续/连续、Ud 公式 |
| 三相全控桥整流 | α、U₂ | 六脉波、自然换相点、α>60° 波形变负 |
| Buck / Boost | D、Ui、L、f、R、C | Uo 公式、ΔI 纹波、CCM/DCM 判据 |
| SPWM 逆变 | m、N、Ud | 载波调制过程、基波幅值、过调制 |
| 双闭环直流调速 | n*、Kp、τn、Idm、TL | 恒流限幅启动、突加负载抗扰、抗饱和 |

## 正确性保证

- 整流模块波形构造经数值积分校验（数值平均 vs Ud 公式，4 组 α 角误差 < 1V）；
- 双闭环模块与同参数 MATLAB/Simulink 模型（3kW/220V/1500r/min 机组，ASR 典型 II 型 h=5 整定）实测对拍：
  - 启动电流平顶：网页 30.0 A / Simulink 30.5 A；
  - 突加额定负载跌落：网页 11.4 r/min / Simulink 10.4 r/min；
  - 稳态段小幅调节波动带：网页 ±10 r/min / Simulink 实测 ±12 r/min（饱和+反馈滤波交互作用的真实行为，两模型一致复现）；
  - 稳态电流均值：网页 ≈15 A / Simulink 14.92 A（理论 15.06 A）。

## 技术形态

- 单个 `index.html`，纯 vanilla JS + Canvas，无任何外部依赖与网络请求；
- 高分屏适配（devicePixelRatio），移动端可用；
- 全部计算本地完成，可作离线教学工具分发。
